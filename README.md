# 🔬 Research & Academic Work

My research focuses on **scalable and adaptive data analytics**, particularly for large-scale and streaming environments.

### 🧠 Anytime Algorithms

Algorithms designed to produce useful results progressively and improve solution quality as additional computation becomes available.

### 🌊 Data Stream Mining

Research involving continuous, high-volume and evolving data streams.

### 🔍 Frequent Itemset Mining

Efficient discovery of frequent patterns from large and streaming datasets.

### 📊 Clustering & Classification

Scalable approaches for analysing large datasets and identifying meaningful structures and patterns.

### ⚡ Parallel & Distributed Analytics

Exploring parallel and distributed approaches for accelerating data-intensive algorithms.
